## [v0.12.0] - 2026-08-23 ([`7ef4274`](https://github.com/grokify/aha-studio/commit/7ef4274))

### Highlights

- Custom field mutations: UPDATE <entity> SET custom.<key> = <value> in AQL (CLI and set_custom_field_values MCP tool) for features, initiatives, and releases, routed through aha-go's GraphQL SetCustomFieldValues
- Idea voter and customer-org sync: idea_endorsements/idea_users/idea_organizations Ent schemas and incremental sync, a get_voter_domain_histogram MCP tool, and a new cache-backed omnisignalcache OmniSignal provider with voter/customer-org tiering
- New omniroadmap package: cache-backed provider.Provider implementation for the omniroadmap-core ecosystem, registered as "aha-studio", reading entirely from the local cache with no Aha API traffic
- aha-mcp-server tool subcommand: invoke any registered MCP tool directly from the shell without a running server session
- Rate-limited sync_data MCP tool and --detailed/--rate-limit sync CLI flags, plus context.Context threaded through cache query methods
- Phase 2 complete: create_release, delete_idea, list_idea_categories, get_feature_ideas MCP tools
- Phase 4 complete: OpenAPI 3.0 spec at /api/openapi.json and Prometheus metrics at /metrics
- Phase 5 complete: get_ideas_statistics and get_features_statistics analytics tools
- Sync resilience: GraphQL feature sync falls back to REST when project resolution fails
